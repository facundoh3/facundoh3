## Projects

### Fintexa — GitOps CI/CD Demo
End-to-end GitOps architecture for automated microservice deployment (React + Spring Boot) on Kubernetes.

- CI with GitHub Actions: build, tag and push to DockerHub
- CD with ArgoCD as the sole deployment responsible
- Kubernetes with separate `dev` and `test` namespaces
- Helm Charts for declarative infrastructure management
- Tag-based deployment strategy: `-dev` tag targets dev namespace, `-test` targets test namespace
- Clean separation between code repositories and infrastructure repository

Repositories: [Frontend](https://github.com/Demo-Fintexa/FrontEnd-Shop) | [Backend](https://github.com/Demo-Fintexa/BackEnd-Shop) | [Infrastructure](https://github.com/Demo-Fintexa/fintexa-gitops-infra)
